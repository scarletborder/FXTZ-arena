# 如何创建和应用 sfx

sfx 属于表现层效果，通常位于 `apps/frontend/src/battle/sfx`，由战局输出中的 effect、projectile、mob 状态或前端事件驱动。

## 创建步骤

1. 在 `apps/frontend/src/battle/sfx` 下添加新的效果模块。
2. 让效果只依赖战局输出状态和 Phaser 场景，不直接修改 `raid-logic` 状态。
3. 在 sfx index 或对应 view 层接入创建逻辑。
4. 确认生命周期：创建、更新、销毁都不会泄漏对象。

## 调用方式

- 由战局 effect 驱动：适合清弹环、爆炸、命中特效等需要与回滚状态一致的表现。
- 由前端本地事件驱动：适合菜单、按钮、非战局结果的提示效果。

## 注意事项

- sfx 不应影响战局 hash。
- 如果某个视觉效果会改变命中、遮挡、实体生成或伤害，它就不是纯 sfx，应进入 `raid-logic`。
- 回滚重放时，同一权威帧应能重建同样的战局输出；前端可自行去重表现层瞬时效果。
