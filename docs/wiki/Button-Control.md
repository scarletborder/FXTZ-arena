# 操作说明

FXTZ-arena 是 60fps tick 推进的 2D 弹幕对战游戏。前端采集输入后交给 `raid-logic`，战局结果由确定性逻辑统一推进。

## 基本操作

| 操作 | 说明 |
| --- | --- |
| 移动 | 控制当前角色在战场中移动。 |
| 鼠标瞄准 | 角色朝向鼠标位置，普通攻击、bomb 或部分能力会使用该朝向。 |
| 普通射击 | 消耗当前角色弹药，生成该角色定义的普通攻击。 |
| 装填 | 按当前角色的装填策略恢复弹药。 |
| 切换角色 | 在主角色和副角色之间切换。 |
| Bomb | 使用当前角色的 bomb，通常包含消弹、无敌或强力攻击。 |
| 主动能力卡 | 使用已装备的主动能力卡。 |

## 输入同步注意

- 战斗逻辑只消费每帧输入状态，不直接读取真实时间或渲染状态。
- 新增快捷键时，需要把输入字段接入 `BattleInputState` 和网络同步流程。
- 会影响战局结果的输入必须进入同步输入；纯 UI、镜头、调试显示不应进入战局 hash。
