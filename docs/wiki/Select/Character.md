# 角色

每套配装选择两个角色：主角色和副角色。战斗中可以切换当前角色，不同角色拥有不同普通攻击、bomb、弹药和装填方式。

## 职业

| 职业       | 当前角色        | 定位                                           |
| ---------- | --------------- | ---------------------------------------------- |
| `suppress` | `reimu`         | 低速诱导弹和消弹 bomb，偏压制与空间控制。      |
| `sniper`   | `marisa`        | 高速激光和长前摇 bomb，偏高爆发。              |
| `assault`  | `sakuya`, `iku` | 近中距离压迫与突击机体。                       |
| `scout`    | `youmu`         | 高速侦察，使用剑气消弹并通过 bomb 短距离突刺。 |
