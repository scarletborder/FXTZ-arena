# Scene 与 UI 规格

## 全局

- UI 和游戏画面全部使用 Phaser 渲染。
- 画面比例 16:9，适配时保持主要游戏区域比例稳定。
- 鼠标在战局中替换为准心。
- 设置中的 debug 模式影响 debug hash 和额外调试信息显示。

## 首页

按钮：

- 开始战斗。
- 靶场。
- 图鉴。
- 设置。

首页应直接进入功能，不做营销式落地页。

## 设置

### 通用

- 设置用户名。
- 开启或关闭 debug 模式。

### 联机

- 设置专用服务器地址。
- 默认监听本地专用服务器。
- 默认端口：22334。
- 显示连接状态。

### 关于

- staff 信息。
- 项目网址。

## 图鉴

整体左右结构。

### 左侧列表

顶部一级分类 tab：

- 角色。
- 能力卡。

最右侧二级分类：

- 角色：突击、压制、侦察、狙击。
- 能力卡：主动使用、被动。

列表主体 item：

- 上下结构。
- 上方为插图。
- 下方为名字。
- 右上角显示 cost。

### 右侧详情

上下结构。

上方展示：

- 角色：攻击时的样子。
- 主动能力卡：使用后的情景。
- 被动能力卡：受影响的效果。

下方展示：

- 角色：名字、职业、移速、弹容、射速、弹速、描述。
- 能力卡：名字、分类、使用次数限制、冷却时间、描述。

## 开始战斗

页面左右分栏。

左半边从上到下：

- 快速匹配。
- 创建房间。
- 房间列表。

右半边从上到下：

- 人机对战。
- 靶场。

### 快速匹配

- 在房间列表中随机选择一个无密码房间加入。
- 不选择有密码房间。

### 创建房间

按钮可用条件：

- 前端能够连接专用服务器。

创建房间参数：

- 地图。
- 是否设置密码。
- 密码输入。
- 房间名。
- 初始命数。
- cost 上限。

### 房间列表

- 房间 item 左右两排展示。
- item 显示房间名字。
- 有密码时，item 内部最左侧显示 lock 图标。
- item 内部最右侧居右显示爱心 + 命数，以及 `costN`。

### 人机对战

- 先进入选择页面。
- 玩家选择后直接进入战斗。
- CPU 从若干预设配装中选择一个。

### 靶场

- 先进入选择页面。
- 无视 cost 上限。
- 玩家可选择任意两名角色和无限能力卡。
- 战局中只有自机和一个靶子。
- 右侧显示训练数据。

## 选择 Scene

功能：

- 玩家选择自己的配装。
- 拖拽出战角色到常驻模式和特殊模式方框。
- 鼠标左键选中或取消选中能力卡。
- 主动使用能力卡最多只能选中 1 张。
- 实时显示 cost 槽。
- 鼠标悬浮 item 时显示确认选中后的 cost 变化。
- 未到达 cost 上限前为绿色，否则为红色。
- 点击“确认出战”。

合法性：

- 必须选择两名角色。
- 不可选择两个同一角色。
- 人物 cost 和能力卡 cost 都计入总 cost。
- 主动使用能力卡最多 1 张；选择新的主动卡时，应取消原主动卡或阻止选择。
- 达到或超过 cost 上限后无法点击“确认出战”。

联机等待：

- 一名玩家确认后，如果对手没有准备好，提示“等待对手准备中”。

## 加载 Scene

进入条件：

- 双方都准备好。

职责：

- 加载战局资源。
- 本地加载完成后向对端或服务器发送 `loading_done`。
- 如果对手未加载好，提示“等待对手加载中”。

## 战局 Scene

进入条件：

- 双方都加载完成。

初始：

- 双方出生在预设出生点。
- 显示开战 HUD。

战斗中：

- 渲染角色、判定点、子弹、激光、bomb、准心、HUD。
- 角色 sprite 为固定三角形外观，切换常驻/另外模式时不改变 sprite 外观。
- 角色判定点圆圈圆心必须位于等腰三角形重心。
- 角色 sprite 周围不常驻显示角色名、模式、弹药量和 bomb 数；只有被命中或使用 bomb 时短暂显示命数与 bomb 数。
- 受击角色进入 3 秒无敌，sprite 在无敌期间闪烁。
- 准心使用清晰加粗的圆圈与对称轴。
- 准心右侧弹药竖条始终显示外轮廓，弹药从上向下减少，装填时从 0 开始增长并显示红色。
- 弹药竖条下方显示 `x/N` 当前弹药量比例。
- 准心下方按剩余 bomb 数逐个显示 bomb 图标；没有 bomb 时不显示图标。
- 准心 HUD 不显示当前角色名称。
- 根据 `raid-logic` 输出事件播放反馈。
- 按住 `Tab` 控制双方信息显示。

结束：

- 一方命数归 0 后进入结算 scene。

## 结算 Scene

展示：

- 胜利一方用户名。
- 对战时间。
- 命中、射击、bomb 使用、死亡等统计数据。

操作：

- 返回房间或开始战斗页。
- 再战入口可后续加入。
