# 能力卡

能力卡用于改变角色基础规则或提供额外主动技能。当前分为主动使用和被动两类。

## 类型

| 类型 | 说明 |
| --- | --- |
| 主动能力卡 | 需要玩家按键触发，有使用次数和冷却。当前配装最多 1 张。 |
| 被动能力卡 | 自动生效或在特定事件触发，可装备多张。 |

## 当前能力卡

| id | 类型 | cost | 简述 |
| --- | --- | --- | --- |
| `spirit_strike_card` | 主动 | 1 | 清除自身周围弹幕，使用次数 3，冷却 20 秒。 |
| `graze_lover` | 被动 | 1 | 擦弹范围提升到 150%。 |
| `backdoor` | 被动 | 1 | 在角色后方生成可消除普通弹的矩形护盾。 |
| `multi_shot` | 被动 | 1 | 普通射击后额外追加 1 枚低速诱导弹。 |
| `ember` | 被动 | 2 | 默认 bomb 数增加到 4，复活后也恢复到 4。 |
| `extra_life` | 被动 | 3 | 初始命数 +1。 |

详见 [能力卡数据](../Data/Ability-Card/index.md)。
