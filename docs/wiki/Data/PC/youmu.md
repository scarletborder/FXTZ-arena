# Youmu

| 字段 | 值 |
| --- | --- |
| id | `youmu` |
| cost | 5 |
| 职业 | `scout` |
| 移速 | `high` |
| 弹夹 | 1 |
| 装填 | 0.5 秒 |

## 普通射击

`youmu_slash`：生成多段短激光组成的剑气弧，能够清除 `couldClear` 的普通子弹；同时从背后向准心方向发射高速可消除普通子弹。

Point tier 提升后，背后射击次数、前方剑气弧数量和背后剑气弧会按角色数据增强。

## Bomb

`youmu_dash_bomb`：向当前朝向突刺最多 72 像素，若超出边界则停在可移动边界内。突刺路径留下宽 24 倍判定点直径的清弹矩形，并在原位置和到达位置各向敌方当前位置发射 6 次高速可消除普通子弹，间隔 5 帧。
