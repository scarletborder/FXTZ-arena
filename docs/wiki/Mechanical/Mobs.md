# 中立怪物

中立怪物由地图或战局配置中的 `mobSpawnerId` 决定。默认战局使用 `default-a`，靶场可使用专门的生成器。

## 当前生成器

| id | 说明 |
| --- | --- |
| `default-a` | 按波次生成示例妖精，并可安排弹幕齐射。 |
| `shooting_range_spawn` | 靶场用生成器，通常用于稳定测试和练习。 |

## 战局行为

- 中立怪物拥有独立 id、位置、血量、active 状态和命中判定。
- 怪物可以发射普通弹或激光，投射物 owner 为 `Neutral`。
- 怪物死亡后会触发死亡逻辑和死亡效果，并从活动列表移除。
- 时间停止期间，生成器和怪物行为会被冻结，但会维护前一帧位置用于渲染插值。

## 帧同步注意

- `nextNeutralMobId` 必须进入 snapshot，否则回滚后可能复用 id。
- 中立怪物参与碰撞和 hash 前需要稳定排序，当前按 id 排序。
- mob spawner 自身状态会影响未来生成，必须实现 snapshot/restore。
