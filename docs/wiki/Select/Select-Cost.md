# 配装 cost

配装阶段通过 cost 限制角色和能力卡组合。普通模式默认 cost 上限为 10，靶场模式无视 cost 上限，但仍校验 id 是否有效、角色是否重复等基础规则。

## 计算规则

- 主角色 cost + 副角色 cost + 所有能力卡 cost = 总 cost。
- 主动能力卡最多选择 1 张。
- 被动能力卡可选择多张，但仍计入总 cost。
- 普通模式下，总 cost 达到或超过上限时不能确认出战。

## 开发注意

- cost 是共享内容数据，角色和能力卡定义修改后，选择页面、校验逻辑和图鉴都应读取同一份定义。
- 靶场可以跳过 cost 上限，但不能跳过内容 id 和角色重复校验。
